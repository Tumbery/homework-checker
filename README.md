# Homework Checker — Цифровой сотрудник для автоматизации проверки домашних заданий

API-приложение на Python, которое использует большую языковую модель (LLM) для автоматической проверки домашних работ студентов. Возвращает структурированную оценку в формате JSON: баллы по критериям, сильные и слабые стороны работы, итоговую оценку и оценку риска плагиата.

## Тема проекта

**Цифровой сотрудник для автоматизации проверки домашних заданий**

## Технологический стек

- **Python** — основной язык разработки
- **FastAPI** — фреймворк для создания HTTP API
- **Pydantic** — валидация данных и механизм структурированного вывода (JSON Schema)
- **OpenAI SDK** — единый интерфейс взаимодействия с LLM
- **Ollama** — локальный запуск моделей (опционально)
- **OpenRouter / Yandex Cloud / OpenAI** — внешние провайдеры LLM (опционально)
